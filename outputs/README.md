# 📦 outputs/ — Resultados generados

> Aquí caen **todos los resultados** que produce el agente y que no son código fuente
> de la app: planes de sprint, investigaciones, borradores, notas de decisión, informes
> del revisor, etc.

## Convención de nombres

```
outputs/AAAA-MM-DD_sprintN_tema.md
```

Ejemplos:
- `2026-06-01_sprint1_definicion-producto.md`
- `2026-06-05_sprint2_plan-monorepo.md`
- `2026-06-08_sprint3_informe-revisor-rls.md`

## Reglas
- Un archivo por entregable; nombre claro con fecha y sprint.
- Lo que sea **decisión estable** del producto/stack se promueve a `context/` o `doc/`,
  no se queda solo aquí.
- Esta carpeta es historial de trabajo; no se borra a la ligera.
