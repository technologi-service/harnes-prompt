# 📂 Carpeta de Prompts

Esta carpeta está destinada a almacenar las secuencias de prompts organizadas por carpetas de roles y pasos para la ejecución estructurada de las tareas del proyecto.

## Estructura y Organización

Los prompts se organizarán por subcarpetas correspondientes a cada sprint o rol definidos en el secuenciador (`doc/secuencias.md`):

- `prompts/sprint-1/`
- `prompts/sprint-2/`
- etc.

## Reglas de los Prompts

1. **Atómicos:** Cada archivo de prompt debe enfocarse en un máximo de **3 objetivos específicos** para garantizar cambios controlados y atómicos.
2. **Plantilla Estándar:** Fácil de escalar y mantener.
3. **Sincronización:** Deben coincidir con los pasos numerados en `doc/secuencias.md`.
